Pegar texto del reporte (ej. copiado de un PDF de AvaOptions)

Pega aquí el contenido de tu reporte: CSV, texto de un PDF, o el HTML de Myfxbook/MT4/MT5.

  • PDF: ábrelo, selecciona todo (Ctrl+A), copia (Ctrl+C) y pega. El lector reconstruye el formato.
  • Consejo: si copias desde Excel o Google Sheets, el separador puede ser una tabulación — no pasa nada, el lector autodetecta coma, tabulación, «;» y «|».
  • HTML de Myfxbook: también puedes abrir el .html con clic derecho → «Ver código fuente» y pegarlo, o simplemente subir el archivo .html.
